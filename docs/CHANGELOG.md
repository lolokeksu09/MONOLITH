# Changelog

## 0.2.0-alpha
- Refined AMOLED home layout, app list and app contextual actions.
- Long-press an app to pin/unpin, reorder pinned apps and open system app details.
- Adjustable app grid (3–6 columns) and app-label visibility; saved locally.
- Swipe up to open the app list; explicit buttons remain for accessibility.
- Automatic app refresh on package install, uninstall, update; restartable app loading.
- Recoverable app-list errors and accompanying tests.
- GitHub Actions prerelease of the debug APK after successful main-branch validation.

## 0.1.0-alpha.2
- Added Android system default-home picker with settings fallback.
- Added date to the clock, adaptive app grid and accessible app actions.
- Added monochrome application icon and explicit drawer pin guidance.
- Cancel superseded app catalog loads to prevent stale UI state.
- Pin logic unit tests and Android lint to CI.

## 0.1.0-alpha.1
- HOME-capable Compose launcher, app drawer and local pinned applications.
