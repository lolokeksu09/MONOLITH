# NOX 1.1 — Studio polish design
Date: 2026-10-23
Status: user-requested improvement to approved NOX 1.0; compatibility-first change.

## Goal
A premium offline AMOLED editor that treats the live shader as the hero, while keeping the existing application ID and persisted presets intact.

## Interaction design
- Home: dominant live scene with restrained typography/gradient legibility; direct scene selector and edit/apply/export.
- Studio: live editor with readable controls, four editorial "looks", deterministic remix, restore scene defaults, and distraction-free full-screen preview.
- Library: searchable list (case-insensitive by preset name or scene identifier), existing edit/select/copy/delete with confirmation.
- Navigation: consistent icons replacing text glyphs; clear selected affordance and touch-friendly targets.
- Styling: true black #000000, near-black raised surfaces #101923, electric blue #30D9FF, text #F2F6FF, secondary #99AFC4, restrained violet.
- Offline-only. Do not add networking, new permissions, server or tracking.

## Domain rules
- SceneLooks.apply retains sceneId, motion, seed and speed; adjusts palette, density and glow.
- SceneLooks.shuffle is deterministic for a given SceneConfig, increments the seed and modifies palette/speed (always normalized); preserves sceneId and motion.
- No database migration or data deletion.
- Existing live wallpaper service, GL backend and export path remain untouched.
- App ID studio.nox.light unchanged; versionCode incremented from 1 to 2, versionName to 1.1.0 so the installed debug build can update in-place under the same signing key.

## Acceptance
Unit tests for look/remix invariants, structural regression tests, Android compile + APK via GitHub Actions. Device runtime remains user acceptance, not claimed as tested in CI.
