# NOX 1.0 — Design specification

Status: design approved 2026-10-23 by requester. Implementation is a distinct local project, unrelated to other repositories.

## Product
NOX is an offline, native Android 16-capable AMOLED living-light wallpaper studio. User creates, previews, tunes, saves, exports, and installs generative animated wallpapers. Three scene families: FLUX (fluid streaks), HALO (orbital light) and NEBULA (particles). PRISM is out of 1.0 scope.

## Device & runtime
Target device: Lenovo Legion Y70 2026 running Motorola-based Android 16 without root. minSdk 26, targetSdk/compileSdk 36. No private permissions or network required. Device-specific behavior depends on firmware/launcher. Supports edge-to-edge, system inset handling and accessibility.

## Interaction contract
- Home: full-size preview, scene cards, Edit and Apply actions.
- Studio: live preview, adjustments (palette, speed 0.0..1.0, glow 0.0..1.0, density 0.0..1.0, motion 0.0..1.0), rename and Save. On cancellation nothing writes.
- Library: list saved named configurations with Preview/Edit/Use/Duplicate/Delete; safe delete confirmation, initially seeded defaults; active selection stored persistently.
- Settings: 30/60/120 FPS profiles, power-saver overrides, enable/disable motion, conservative fallback when thermal status warrants.
- Export: PNG using system document picker (URI grant), user-chosen destination. No broad storage permissions.
- Apply: ACTION_CHANGE_LIVE_WALLPAPER with component, system UI confirmation required; cancellation doesn't claim success. Android launcher decides touch delivery and lockscreen compatibility.

## Rendering contract
- One GLSL/OpenGL ES shared renderer for Activity SurfaceView preview, WallpaperService.Engine, and offscreen bitmap rendering. Separately owned EGL contexts/surfaces, never shared mutable GL objects.
- RGB palette and four numeric parameters plus deterministic seed are stored for every preset.
- Wallpaper loop only runs while surface exists AND visible; release resources after surface is destroyed. No wake locks.
- Motion sensor only registered while a preview or live wallpaper is both visible and motion enabled, with clean unregistration.
- Cap FPS at 30/60/120; clamp to 30 in battery saver or moderate thermal load, 15 under severe load; target rates are ceilings, not guarantees.
- Resize handles 1440x3168 portrait as well as arbitrary dimensions and inset layout.

## Modules
- `:app`: Compose UI, navigation states, editor, Android actions.
- `:core:model`: immutable scenes, settings, validations.
- `:core:renderer`: EGL, shader engine, offscreen export, SurfaceView.
- `:core:data`: Room presets and DataStore settings.
- `:feature:wallpaper`: service, visibility and sensors.

## Storage & security
Room stores local preset rows. DataStore tracks active id, FPS profile, and global motion toggle. No INTERNET or media access permissions. No analytics. All names validated and trimmed. Prefer local asset shaders.

## Test/acceptance matrix
- Unit: parameter clamping, scene mode lookup, palette parsing, empty names, deterministic seed; storage tests (instrumented or Robolectric) for persistence, duplicates and deletion.
- Build: `./gradlew :app:assembleDebug` and test tasks.
- Device (requires physical user phone): apply wallpaper, preview, relaunch/persist, Android 16 edge-to-edge, battery saver/thermal throttling, wallpaper hidden yields no frame renders, lockscreen/launcher touch conditional, long-run battery and graphics.
- APK is an installable debug build with local development signing; production release signing requires owner's private signing key.

## Non-goals 1.0
Video export, cloud gallery, accounts, online templates, background services outside WallpaperService, privileged system settings, audio reactive mode, external image import, PRISM, automation.
