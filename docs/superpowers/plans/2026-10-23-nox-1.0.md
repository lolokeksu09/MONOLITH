# NOX 1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a real, offline Android wallpaper creator with 3 GPU scenes, persistent presets, editor and installable APK.

**Architecture:** 5 Gradle modules; shared GLES renderer and separate Activity/Wallpaper EGL surfaces; Compose with StateFlow; Room for presets, DataStore for global settings.

**Tech Stack:** Kotlin 2.3.20, Android Gradle Plugin 8.13.2, Gradle 8.13, Compose BOM 2026.09.00, API 36, Room, DataStore, GLES3.

**Spec:** `docs/superpowers/specs/2026-10-23-nox-1.0-design.md`

## Global Constraints
- Offline, minSdk26/targetSdk36; do not declare INTERNET permission.
- No runtime privileged/broad storage permission; SAF PNG export.
- Scene identifiers and UX copy: FLUX, HALO, NEBULA; dark palette #000000, cyan #30D9FF.
- Wallpaper renderer stops when hidden and sensor unsubscribes.
- Project must not touch existing repositories.

## Review Focus
1. Surface lost during frame loop -> no EGL leaks or crash; test lifecycle.
2. Invalid or missing preset -> safe fallback FLUX; unit test.
3. Shader compilation failure -> error displayed instead of black screen; manual test.
4. User cancels PNG document -> no export attempt; UI test.
5. Power saver on a 120 Hz phone -> FPS falls to <=30; unit + device test.
