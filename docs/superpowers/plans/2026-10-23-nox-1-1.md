# NOX 1.1 Premium Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement task-by-task. Steps use checkbox syntax.

**Goal:** Make NOX 1.1 a visually distinct and functionally richer native AMOLED app without losing the working NOX 1.0 wallpapers/presets.

**Architecture:** Retain the five existing modules. Put deterministic appearance presets/remix in :core:model; implement look tools, search and immersive previews only in :app.

**Tech Stack:** Kotlin, Jetpack Compose, Room/DataStore, OpenGL ES 3.0, JUnit4, Python structural tests, GitHub Actions Gradle 8.13.

**Spec:** docs/superpowers/specs/2026-10-23-nox-1-1-design.md

## Global constraints
- Preserve studio.nox.light applicationId and Room schema version 1.
- No new dangerous permissions; do not alter the EGL renderer.
- Keep current navigation and all existing use/edit/duplicate/delete actions functional.
- Android API 36, AGP 8.13.2, Compose BOM 2025.10.01.
- Version 1.1.0 (code 2), debug variant studio.nox.light.preview to preserve existing 1.0 installation; CI debug APK as artifact.

## Review Focus
- Invalid HEX text must never alter scene colors.
- Shuffle from identical input must produce identical result and a distinct seed.
- Preview dialog must not accidentally apply live wallpaper.
- Search should include names and identifiers, case insensitive.
- Preview package must not overwrite or uninstall 1.0; existing presets stay in the original app.
