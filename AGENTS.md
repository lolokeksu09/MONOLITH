# CONTEXT CAPSULE development rules

- Check the current commit before making changes.
- Use Development & Design Skills, approved specification and implementation plan before adding app code.
- Every patch must have a GitHub commit, updated documentation, and accurate test/CI status.
- Do not claim an APK exists until it has been compiled and verified.
- Keep Android native, Kotlin/Compose, offline-first, no root, no paid AI API.
- Only read public GitHub data; never upload private chat content without informed approval.
- Preserve verified evidence versus user-confirmed and unverified notes.
- Ask before destructive data import, deletion, or sharing private context.
